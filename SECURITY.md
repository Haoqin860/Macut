# Security reporting

Please use the repository's private vulnerability reporting feature, when
available, for security-sensitive reports. Do not include passwords, tokens,
personal clipboard history, local databases or full system diagnostics in public
issues.

Macut 0.1.x is an early public release. The published binary is ad-hoc signed and
is not Apple-notarized. Only install packages from this repository's Releases
page, and compare the SHA-256 checksum before installation.
