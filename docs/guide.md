# Macut

给 macOS 的原生剪贴板历史工具。SwiftUI + AppKit，中文界面，文字与图片混合历史，所有内容保存在本机。

## 开始使用

打开 `build/Macut.app`，或从 DMG 拖入「应用程序」后打开。Macut 常驻菜单栏，不占用 Dock。

- `⌘⇧V`：呼出 / 收起面板；呼出后直接输入关键词。
- 点击菜单栏的叠纸图标：打开面板；右键：设置、暂停或退出。
- `⌥` 点击菜单栏图标：暂停 / 继续记录。
- `↑` / `↓`：选择记录；`↩`：使用选中内容。
- `⌘↩`：以纯文本使用文字；对图片、文件不生效。
- `⌘1` 至 `⌘9`：使用当前结果中的前九条。
- `⌘P`：收藏 / 取消收藏；`⌘⌫`：删除选中记录。
- `Tab` / `⇧Tab`：切换分类；`⌘F`：回到搜索。
- 空搜索时按空格，或点击图片预览：放大图片；在图片预览中按空格 / Esc 返回。
- `⌘\`：展开 / 收起右侧预览；`⌘,`：设置；`Esc`：收起。
- 双击记录可直接使用；单击只选中，方便预览。

在设置的「呼出面板」中可录制自己的全局快捷键。如果注册失败，会保留旧快捷键。系统或其他应用也可能使用同一组合；发生冲突时可换一个组合。

## 自动粘贴与权限

呼出和记录历史不要求辅助功能权限。自动粘贴需要你在「系统设置 → 隐私与安全性 → 辅助功能」中允许 Macut。

未授权或关闭自动粘贴时，回车会把内容复制到系统剪贴板并收起面板；回到原应用按 `⌘V` 即可。已授权时，Macut 会核对原应用是否回到前台，再发送粘贴键；焦点恢复超时则保留复制结果。安全输入框以及某些应用可能不接受模拟粘贴，仍可手动使用 `⌘V`。

辅助功能授权没有在开发过程中自动开启。登录时启动也默认关闭，可自行在设置里打开。登录项的实际启用状态由 macOS 管理。

## 保存和隐私

- 纯文字、HTML、RTF、RTFD、PNG、TIFF、链接和文件引用保存在 `~/Library/Application Support/Macut/`。
- `history.json` 保存可搜索的元数据；`Blobs/` 单独保存原始内容和图片缩略图。图片预览会缩小显示，粘贴仍使用保存的原始表示。
- 默认保留 500 条普通记录、30 天未使用历史、512 MB 内容容量。收藏不自动删除，收藏占用也计入容量。
- 单次读取总量超过 64 MB 的内容跳过记录；PNG 和 TIFF 同时存在时仅保存 PNG，避免重复存储大图片。
- 自动跳过带有 concealed / transient 等敏感标记的复制，可设置排除应用和暂停记录。**未标记的密码或其他敏感文字仍可能被记录**，请按自己的使用场景设置排除应用。
- 来源应用由捕获时的前台应用推断，是近似信息，不是系统提供的可靠复制来源。自动化工具或快速切换应用时可能显示不准确。
- 剪贴板通过系统变化计数定期检查；在两次检查之间被连续覆盖的内容可能无法记录。
- 文件历史保存文件引用，不备份文件本身。单个本地图片文件会生成图片预览，且会进入图片分类；没有扩展名的图片缓存文件也按内容识别。原文件被移动、删除或失去访问权限后，缓存缩略图可继续展示，原文件引用粘贴仍可能失效。
- 微信等应用的图片缓存可能受 macOS 保护。新复制优先使用系统剪贴板提供的文件访问授权；旧条目没有预览时，可点击「选择原图片以允许预览…」并由你选择对应文件。不会要求全盘访问，也不会扫描聊天记录。无法访问或已删除的原文件仍可能无法生成预览。
- 搜索和文字预览索引最多保留前 60,000 个字符，原始剪贴板载荷仍单独保留。第一版没有图片 OCR 搜索、云同步或 AI 上传。
- 清空普通历史会保留收藏；不会清空当前系统剪贴板。历史文件使用当前用户可访问的本地目录，不做应用层加密。
- 无网络请求、账号、遥测和第三方运行时依赖。

## 构建和验证

要求 macOS 14+ 与可用的 Swift 工具链。当前包针对 Apple Silicon 构建。

```sh
./Scripts/build-app.sh
./Scripts/run-checks.sh
./Scripts/package-dmg.sh
```

构建脚本生成应用图标并进行 ad-hoc 本机签名。当前交付没有 Developer ID 签名或 Apple 公证。修改后重新构建可能需要 macOS 重新确认辅助功能授权；日常使用应保留稳定的安装位置和版本。

`run-checks.sh` 使用独立检查程序，不要求完整 Xcode / XCTest。检查包括去重、富文本原样保存、多文件边界、收藏和容量规则、时间保留、删除、保存失败回滚、损坏索引保护、中文多词搜索和图片缩略图 / 原数据。

用于界面展示的 `--demo` 启动参数使用独立临时历史并关闭剪贴板采集，不接触日常历史。

工程参考与设计素材说明见 [docs/development.md](docs/development.md)。
