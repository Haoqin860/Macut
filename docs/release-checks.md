# 公开发布检查

- 只提交源码、构建脚本、说明、许可、静态网页和审阅过的生成素材。
- 不提交本机数据库、偏好设置、桌面截图、运行日志、构建缓存、签名证书或密钥。
- 提交身份使用项目名与 GitHub 隐藏邮箱，不使用本机全局 Git 身份。
- Release 编译使用路径映射；剥离调试符号后重新进行 ad-hoc 签名。
- 构建产物去掉扩展属性；安装包不从个人 Application Support 目录复制任何文件。
- 安装镜像只包含应用、使用说明和 Applications 快捷方式。
- 检查待提交文件和应用载荷中的个人目录、开发机器标识、常见凭据格式及不允许的文件类型。审计只报告规则类别与相对文件名，不回显匹配内容。
- GPT 素材不包含真实文档、账号、聊天记录或桌面内容；网站演示数据全部虚构，不调用剪贴板 API。
- 只读挂载 DMG 校验签名、Info.plist、可执行文件与图标的一致性；发布 SHA-256 校验文件。

这些检查面向公开文件和发布载荷，不代表安全漏洞审计或个人信息的绝对保证。隐私行为与已知边界详见根目录 PRIVACY.md。
