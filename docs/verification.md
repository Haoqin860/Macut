# 验证范围

核心检查程序覆盖以下 17 个场景：

1. 去重时保留收藏和最初复制时间。
2. 富文本及原始表示无损保存。
3. 多文件边界和顺序保留。
4. 数量清理保护收藏。
5. 收藏占用计入内容容量。
6. 按最后使用时间清理。
7. 删除索引和对应载荷。
8. 写入失败保留现有索引并清理新载荷。
9. 损坏索引报错且不覆盖。
10. 中文、多关键词与大小写搜索。
11. 图片缩略图尺寸及原始数据保留。
12. 图片文件显示预览，文件粘贴载荷保持不变。
13. 无扩展名图片缓存文件的内容识别。
14. 旧文件历史补齐预览，并保留收藏、ID 和载荷。
15. 缺失、非图片和多文件条目保持普通文件处理。
16. 原图片文件删除后，已缓存缩略图仍可读取。
17. 按需授权预览只接受对应的原图片，拒绝不相关文件且保留粘贴载荷。

运行 Scripts/run-checks.sh 获取当前源码的实际结果。

原生界面开发验证涵盖默认及自定义快捷键呼出、搜索框焦点、中文搜索、收藏、图片筛选、图片放大与返回、未授权时的复制回退、重启恢复和设置布局。

自动粘贴需要使用者自行授予辅助功能权限。不同应用、安全输入框、系统版本以及文件提供器的剪贴板格式可能存在差异。登录启动的完整登出 / 登录流程和所有第三方应用兼容性不在自动检查覆盖范围内。
